================================================================================
          LOGIBOX DUAL ESP32 SETUP INSTRUCTIONS
================================================================================

This guide explains how to set up two ESP32 boards to work together:
  - ESP32 #1: Keypad + LCD (OTP Verification)
  - ESP32 #2: Door Controller (Relay + Sensors)


================================================================================
                        HARDWARE REQUIRED
================================================================================

For ESP32 #1 (Keypad/LCD) - You already have:
  ✓ ESP32-S3 DevKit
  ✓ 4x4 Keypad
  ✓ I2C LCD (16x2 or 20x4)
  ✓ Jumper wires

For ESP32 #2 (Door Controller) - New:
  ✓ ESP32 DevKit (30-pin)
  ✓ 4-Channel Relay Module
  ✓ 3x Solenoid Locks (12V)
  ✓ 3x Reed Switches (door sensors)
  ✓ 3x IR Sensors (FC-51) (parcel detection)
  ✓ 12V Power Supply (3A or higher)
  ✓ Breadboard + Jumper Wires


================================================================================
                     PART 1: ESP32 #2 (DOOR CONTROLLER)
================================================================================

STEP 1: CONNECT THE RELAY MODULE
-------------------------------
The relay module controls the solenoid locks.

Connect relay module to ESP32:
  Relay IN1 → GPIO 18  (controls Door 1)
  Relay IN2 → GPIO 19  (controls Door 2)
  Relay IN3 → GPIO 21  (controls Door 3)
  Relay IN4 → (unused - can use if you add a 4th door)

  Relay VCC  → 5V (or 3.3V if your relay is 3.3V compatible)
  Relay GND  → GND

NOTE: Most relay modules work with 5V signal. If your relay needs 5V
but ESP32 outputs 3.3V, you may need a level shifter OR use a relay
that works with 3.3V logic.


STEP 2: CONNECT SOLENOID LOCKS
-----------------------------
Each solenoid lock needs its own power source (12V).

For Door 1:
  Solenoid positive (+) → Relay NO1 (Normally Open)
  Solenoid negative (-)  → 12V Power Supply negative (-)

  Power Supply 12V (+) → Relay COM1 (Common)

For Door 2:
  Solenoid positive (+) → Relay NO2
  Solenoid negative (-)  → 12V Power Supply negative (-)
  Power Supply 12V (+) → Relay COM2

For Door 3:
  Solenoid positive (+) → Relay NO3
  Solenoid negative (-)  → 12V Power Supply negative (-)
  Power Supply 12V (+) → Relay COM3

IMPORTANT: Make sure all negative (-) wires are connected together:
  - 12V Power Supply negative
  - Solenoid negative
  - ESP32 GND (for common ground)


STEP 3: CONNECT REED SWITCHES (DOOR SENSORS)
--------------------------------------------
Reed switches detect if the door is open or closed.

Connect one wire of each reed switch to GND on ESP32.
Connect the other wire to the GPIO pins:

  Reed Switch Door 1 → GPIO 22
  Reed Switch Door 2 → GPIO 23
  Reed Switch Door 3 → GPIO 25

The code uses INPUT_PULLUP, so you don't need external pull-up resistors.
When magnet is NEAR reed switch = door is CLOSED (HIGH)
When magnet is FAR from reed switch = door is OPEN (LOW)


STEP 4: CONNECT IR SENSORS (PARCEL DETECTION)
---------------------------------------------
FC-51 IR sensors detect if a parcel is placed inside the vault.

Connect each IR sensor:

  IR Sensor Door 1:
    VCC  → 3.3V (or 5V)
    GND  → GND
    OUT  → GPIO 12

  IR Sensor Door 2:
    VCC  → 3.3V (or 5V)
    GND  → GND
    OUT  → GPIO 13

  IR Sensor Door 3:
    VCC  → 3.3V (or 5V)
    GND  → GND
    OUT  → GPIO 14

NOTE: Adjust the sensitivity knob on the IR sensor using a screwdriver:
  - Turn clockwise = more sensitive (detects further)
  - Turn counter-clockwise = less sensitive

Test: IR sensor outputs LOW when object detected, HIGH when clear.

================================================================================
                     PART 2: ESP32 #1 (KEYPAD/LCD)
================================================================================

STEP 1: UPDATE THE CODE
-----------------------
In the file LogiBox_OTP_Vault.ino, find this section around line 47:

  // Door Controller ESP32 IP - change to match your ESP32 #2 IP
  const char* DOOR_CONTROLLER_IP = "192.168.1.150";
  const int DOOR_CONTROLLER_PORT = 80;

Change "192.168.1.150" to the IP address that your Door Controller
ESP32 will use (see Step 2 below).


STEP 2: UPLOAD AND FIND IP
---------------------------
1. Upload the Door Controller code (LogiBox_Door_Controller.ino) to ESP32 #2
2. Open Arduino IDE Serial Monitor (115200 baud)
3. Look for a line that says "IP Address: 192.168.1.xxx"
4. Copy that IP address

Example output:
  === LogiBox Door Controller Starting ===
  Connecting to WiFi...
  WiFi connected!
  IP Address: 192.168.1.150

5. Update the DOOR_CONTROLLER_IP in ESP32 #1's code with this IP
6. Re-upload the Keypad/LCD code to ESP32 #1


================================================================================
                     PART 3: TESTING
================================================================================

TEST 1: TEST DOOR CONTROLLER API
--------------------------------
After uploading to ESP32 #2, open your web browser and visit:

  http://<YOUR_ESP32_IP>/status

Example:
  http://192.168.1.150/status

You should see something like:
  {"door1":{"open":false,"parcel":false},"door2":{"open":false,"parcel":false},"door3":{"open":false,"parcel":false}}

- "open":true  means door is OPEN
- "open":false means door is CLOSED
- "parcel":true  means parcel DETECTED
- "parcel":false means NO parcel


TEST 2: TEST UNLOCKING A DOOR
-----------------------------
In your browser, visit:

  http://<YOUR_ESP32_IP>/open/1

You should hear the relay click and the door should unlock for 0.5 seconds
then lock again automatically.

Try:
  http://192.168.1.150/open/2
  http://192.168.1.150/open/3


TEST 3: TEST SENSORS
--------------------
Open door 1 → Refresh /status → "door1":{"open":true,...}
Close door 1 → Refresh /status → "door1":{"open":false,...}

Place object in front of IR sensor 1 → Refresh /status → "door1":{"parcel":true,...}
Remove object → Refresh /status → "door1":{"parcel":false,...}


TEST 4: FULL INTEGRATION TEST
-----------------------------
1. Make sure both ESP32 boards are powered on and connected to WiFi
2. On ESP32 #1 (Keypad/LCD), select a vault (1, 2, or 3)
3. Enter the correct OTP
4. After verification, ESP32 #1 should call ESP32 #2
5. You should see "ACCESS GRANTED" on the LCD
6. The corresponding door on ESP32 #2 should unlock


================================================================================
                     TROUBLESHOOTING
================================================================================

PROBLEM: "ERR_CONNECTION_REFUSED" when calling door controller
SOLUTION:
  - Check that ESP32 #2 is powered on
  - Verify the IP address is correct in ESP32 #1's code
  - Make sure both ESP32s are on the same WiFi network
  - Check Serial Monitor for errors

PROBLEM: Door doesn't unlock (no click sound)
SOLUTION:
  - Check relay connections (VCC, GND, IN pins)
  - Verify 12V power supply is working
  - Check that solenoid wires are connected properly

PROBLEM: IR sensor always shows "parcel detected"
SOLUTION:
  - Adjust the sensitivity knob with a screwdriver
  - Make sure nothing is in front of the sensor
  - Check wiring (VCC, GND, OUT)

PROBLEM: Reed switch always shows "door open"
SOLUTION:
  - Make sure magnet is close to the reed switch
  - Check wiring connections
  - Try reversing the reed switch wires

PROBLEM: One ESP32 can't connect to WiFi
SOLUTION:
  - Verify WiFi credentials are correct
  - Make sure you're using 2.4GHz WiFi (not 5GHz)
  - Check that your router allows new devices


================================================================================
                     IP ADDRESS SETTINGS
================================================================================

In the Door Controller code (LogiBox_Door_Controller.ino), you can set a
static IP address. Look for this section around line 40:

  IPAddress staticIP(192, 168, 1, 150);
  IPAddress gateway(192, 168, 1, 1);
  IPAddress subnet(255, 255, 255, 0);

Change these to match your network:
  - staticIP: The IP you want for the ESP32 (must be available)
  - gateway: Your router's IP address (usually ends in .1)
  - subnet: Usually 255.255.255.0 for home networks

To find your network settings:
  - Windows: Open Command Prompt, type "ipconfig"
  - Look for "Default Gateway" and "Subnet Mask"
