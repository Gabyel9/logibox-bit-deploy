================================================================================
                LOGIBOX ESP32 SETUP INSTRUCTIONS
================================================================================

This guide explains how to set up the LogiBox delivery vault hardware:

  - ESP32 #1: Keypad + LCD (OTP Verification + Camera Trigger)
  - ESP32-CAM: Snapshot camera (delivery evidence)

There is no separate door-controller board. The keypad ESP32 verifies the OTP
and starts/stops the ESP32-CAM so it captures delivery-evidence frames.


================================================================================
                         HARDWARE REQUIRED
================================================================================

For ESP32 #1 (Keypad/LCD) - You already have:
  [x] ESP32-S3 DevKit
  [x] 4x4 Keypad
  [x] I2C LCD (16x2 or 20x4)
  [x] Jumper wires

For ESP32-CAM (Snapshot Camera) - New:
  [ ] AI-Thinker ESP32-CAM board (OV2640)
  [ ] USB-TTL (FTDI/CP2102/CH340) adapter, 3.3V
  [ ] Jumper wires


================================================================================
                       PART 1: KEYPAD ESP32 (ESP32 #1)
================================================================================

WIRING (unchanged)
------------------
  Keypad Row 1  -> GPIO 4
  Keypad Row 2  -> GPIO 5
  Keypad Row 3  -> GPIO 6
  Keypad Row 4  -> GPIO 7
  Keypad Col 1  -> GPIO 15
  Keypad Col 2  -> GPIO 16
  Keypad Col 3  -> GPIO 17
  Keypad Col 4  -> GPIO 18
  LCD (I2C)     -> GPIO 1 (TX), GPIO 3 (RX), 5V, GND  (address 0x27)

CODE CONFIG (LogiBox_OTP_Vault.ino)
-----------------------------------
  - WIFI_SSID / WIFI_PASSWORD: your 2.4GHz network
  - DEVICE_ID: must match a device doc in Firestore, e.g. devices/esp32-test-001
  - FUNCTION_URL: your deployed /api/device-verify-otp endpoint
  - CAMERA_IP: static IP of the ESP32-CAM (see Part 2), default 192.168.1.151

UPLOAD
------
  1. Open LogiBox_OTP_Vault.ino in Arduino IDE
  2. Board: ESP32-S3 Dev Module, USB CDC on boot enabled
  3. Install libraries: Keypad, LiquidCrystal I2C, ArduinoJson
  4. Upload and open Serial Monitor @ 115200


================================================================================
                       PART 2: ESP32-CAM (SNAPSHOT CAMERA)
================================================================================

The ESP32-CAM has no USB port, so you flash it through a USB-TTL adapter:

WIRING (USB-TTL <-> ESP32-CAM)
-------------------------------
  USB-TTL 3.3V  -> ESP32-CAM 3.3V
  USB-TTL GND   -> ESP32-CAM GND
  USB-TTL TX    -> ESP32-CAM GPIO3 (RX)
  USB-TTL RX    -> ESP32-CAM GPIO1 (TX)
  USB-TTL DTR/3.3V -> GPIO0 (hold to GND while powering to enter flash mode)

FLASHING
--------
  1. Connect GPIO0 to GND, then plug in / power the ESP32-CAM
  2. Open LogiBox_ESP32CAM.ino in Arduino IDE
  3. Board: AI-Thinker ESP32-CAM
     - PSRAM: Enabled
     - Flash: 4MB
     - Partition: Huge APP
     - Flash Mode: QIO
  4. Install library: esp32-camera (espressif)
  5. Select the USB-TTL serial port and upload
  6. Remove the GPIO0-to-GND jumper and press the reset button
  7. Open Serial Monitor @ 115200 and note the static IP (default 192.168.1.151)

CODE CONFIG (LogiBox_ESP32CAM.ino)
-----------------------------------
  - WIFI_SSID / WIFI_PASSWORD: MUST be the SAME network as the keypad ESP32
  - DEVICE_ID: devices/esp32-cam-001 in Firestore (ownerUid must be set)
  - FUNCTION_URL: your deployed /api/camera-upload endpoint
  - staticIP: must match CAMERA_IP in LogiBox_OTP_Vault.ino (default 192.168.1.151)

CAMERA COMMANDS (LAN HTTP)
--------------------------
  http://192.168.1.151/start         -> begin capturing every 5 seconds
  http://192.168.1.151/start?vault=2 -> begin capturing, tag session "vault 2"
  http://192.168.1.151/stop          -> stop capturing

The keypad calls these automatically when a delivery session starts/stops.


================================================================================
                           TESTING
================================================================================

TEST 1: CAMERA ALONE
--------------------
  1. Power the ESP32-CAM on the same WiFi as the keypad
  2. Visit http://192.168.1.151/start in a browser
  3. Open the web app -> Camera page -> "Captured Sessions"
  4. A session with new frames should appear every 5 seconds

TEST 2: KEYPAD + CAMERA (END-TO-END)
------------------------------------
  1. Power both ESP32s and make sure they are on the same WiFi
  2. Sign in to the web app as the device owner
  3. On the keypad, press any key -> "Select Vault" -> pick a vault (1/2/3)
  4. Enter the correct OTP -> "ACCESS GRANTED"
  5. The camera starts capturing and uploads frames tagged with that vault
  6. In the web app, Camera page shows the session; download a frame


================================================================================
                         TROUBLESHOOTING
================================================================================

PROBLEM: ESP32-CAM won't enter download mode
SOLUTION:
  - GPIO0 must be held to GND BEFORE power is applied
  - Keep the jumper in place until the upload starts
  - Some USB-TTL adapters need EN grounded; try powering via 5V + EN to GND

PROBLEM: Keypad says OTP verified but no session appears in the app
SOLUTION:
  - Confirm both ESP32s are on the SAME 2.4GHz WiFi network
  - Check devices/esp32-cam-001 in Firestore has your ownerUid set
  - Test the camera alone first (TEST 1)

PROBLEM: No frames captured
SOLUTION:
  - Check the ESP32-CAM Serial Monitor for upload errors (HTTP code)
  - Verify FUNCTION_URL points to your deployed /api/camera-upload
  - Make sure the ESP32-CAM's WiFi credentials match the keypad's

PROBLEM: Camera works but session label is missing/empty
SOLUTION:
  - Sessions started from the keypad include ?vault=N. Sessions started
    manually via /start have no vault and appear under "Unsorted".


================================================================================
                         IP ADDRESS SETTINGS
================================================================================

Both firmwares use static IPs on the same subnet. Adjust to your network:

  LogiBox_ESP32CAM.ino:
    IPAddress staticIP(192, 168, 1, 151);
    IPAddress gateway(192, 168, 1, 1);
    IPAddress subnet(255, 255, 255, 0);

  LogiBox_OTP_Vault.ino: CAMERA_IP must match the ESP32-CAM's staticIP.

To find your network settings:
  - Windows: "ipconfig" -> Default Gateway / Subnet Mask
